###### 2026/09/01

* `Улучшение` Добавлен `.python/prepare_release.py` для сборки и проверки подписанного universal APK, проверки версии, расчета CRC32 и SHA-256, а также атомарного создания `SHA256SUMS.txt` и английского `RELEASE_NOTES.md`
* `Улучшение` Унифицировать оформление README и управление версиями платформы Gradle

* `Улучшение` Скрипт генерации документации обновлен до единой реализации, общей для родственных плагинов: обнаружение расхождений через `--check`, сверка ключей и структуры между языками, блокировка полноширинных символов и проверка согласованности версий
* `Улучшение` Инструкции центра плагинов (`plugin_instruction.md`) включены в тот же многоязычный конвейер генерации из JSON, что устранило сопровождение двойного источника
* `Улучшение` Добавлена дорожная карта ROADMAP.md, установлены двусторонние перекрестные ссылки и сравнение с родственным плагином Pinyin

# v1.0.0

###### 2026/07/15

* `Функция` Сервис плагина Pinyin4j: идентификатор плагина `pinyin4j`, автоматически обнаруживается и вызывается AutoJs6 через `org.autojs.plugin.PINYIN4J`, оборачивает библиотеку `com.belerweb:pinyin4j:2.5.1`
* `Функция` API преобразования пиньиня: `pinyin4j.of(text, options)` посимвольно превращает китайский текст в пиньинь; строка, переданная вторым аргументом, сразу используется как разделитель
* `Функция` API восстановления тонов: `pinyin4j.as(text)` превращает пиньинь с цифровыми тонами (например `han4`) в пиньинь с тоновыми знаками (например `hàn`), соответствует методу AIDL интерфейса `asTone`
* `Функция` Гибкая система параметров: псевдонимы вроде `case` / `tone` / `v` / `sep` и краткие значения вроде `MARK` / `NUMBER` / `NO`; недопустимые значения вызывают локализованные сообщения об ошибках
* `Функция` Многоязычные ресурсы: метаданные плагина и инструкции охватывают 10 языков
* `Функция` README и CHANGELOG генерируются как многоязычный Markdown из JSON источников скриптом `.python/generate_markdown.py`
